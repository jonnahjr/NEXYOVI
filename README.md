## 🌌 Overview
**Nexyovi** is a next-generation technology agency focusing on robust network infrastructure, AI-driven solutions, cybersecurity, and enterprise-scale software engineering. This repository contains the **flagship frontend portal**, completely engineered with a cutting-edge **Dark "Bipolar Tech" Aesthetic**, combining glassmorphism, heavy contrast, and dynamic scroll animations to deliver a premium, intelligence-oriented corporate experience.

---

## 🎨 UI/UX Design System
The entire platform has been systematically overhauled from standard corporate templates to a **high-converting, authoritative "Technical Briefing" architecture.**

- **Theme Palette:** Deep navy backgrounds (`#080A0D`, `#060709`), stark white typography, and vibrant neon accents (Violet, Emerald, Orange, Cyan) mapping to specific capabilities.
- **Glassmorphism & Blurs:** Heavy utilization of `backdrop-blur` and absolute-positioned radial blurs to create glowing, futuristic "nodes" that reflect data and network concepts.
- **Micro-Interactions:** Sub-second hover states via `framer-motion`, transforming static cards into interactive data modules with rotating arrows, expanding tags, and glowing borders.
- **Typography:** Ultra-tight tracking on main headlines (`tracking-tighter`), contrasted with micro-spaced tactical metadata (`tracking-[0.4em] uppercase`).

## 🏗️ Core Architecture & Pages

### 1. 🏢 Industries Hub (`/industries`)
A completely unified hub replacing isolated industry pages. Features an interactive left-side grid and a sticky, dynamic right-side detail panel that injects respective "Intelligence Briefings" (Fintech, HealthTech, GovTech, Retail, EduTech).

### 2. ⚡ Services Architecture (`/services`)
A highly optimized, long-vertical funnel:
- Isometric Hero Section (Pure CSS Data Modules)
- "Glassmorphic" 7-Point Service Grid Structure
- Trust Bar & Key Performance Metrics
- 6-Point Process Matrix
- Interactive FAQ Accordion
- Floating AI AI Chat Assistant 

### 3. 👥 Corporate Identity (`/company`)
Broken down into an elite 9-section narrative detailing Mission, Vision, Values, Elite Engineering standards, and interactive Leadership grids. 

### 4. 🛰️ Contact Mesh (`/contact`)
A dual-hub strategy showcasing global headquarters (Addis Ababa & Miami Division), supported by an asymmetric, tactical "Operational Request" data form.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) and npm installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/jonnahjr/NEXYOVI.git

# Navigate into the frontend application directory
cd NEXYOVI/frontend

# Install core dependencies
npm install

# Start the high-performance local server
npm run dev
```

The application will be accessible via `http://localhost:5173`.
