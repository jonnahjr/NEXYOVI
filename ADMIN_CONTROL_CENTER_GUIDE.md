## 🔄 WORKFLOW EXAMPLE

### Publishing a New Service

1. Go to **Site Content** → Services
2. Click **+ Add Service**
3. Fill in:
   - Service title
   - Description
   - Icon/image
   - Features list
   - Pricing (if applicable)
4. Click **Save**
5. Service appears live on website immediately

### Adding a Team Member

1. Go to **Team Members** → **+ Add Member**
2. Enter:
   - Name
   - Role
   - Bio
   - LinkedIn URL
   - Upload photo
3. Select department
4. Set tier (if leadership)
5. Save → Member profile goes live

### Responding to Inquiry

1. Dashboard shows new message
2. Go to **Messages** → **New** tab
3. Click message to open
4. Read inquiry details
5. Click **Respond**
6. Compose response
7. Send → Auto-recorded in system
